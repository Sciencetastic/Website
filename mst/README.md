# NES Maker `.MST` toolkit

Headless reader/editor for NES Maker 4.5.9 project files. Start with **[NESMAKER_MST_GUIDE.md](NESMAKER_MST_GUIDE.md)**
(written for AI agents: format map, safe edit recipes, what is verified vs. untested).

```
python -m nesmaker_mst verify|info|screen|tree|diff|set-tile ...
MST_SAMPLES=/path/to/Projects python -m unittest discover -s tests -v
```
